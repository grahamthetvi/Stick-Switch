Stick-Switch calibrator

USB serial at 115200 baud. Open this page in Chrome or Edge (GitHub Pages is HTTPS, which Web Serial requires). Safari and Firefox cannot use Web Serial.

Plug the board in over USB. Slide the power switch OFF while programming firmware, then connect here. Calibration auto-saves to NVS; SAVE is only a confirmation dump. HID keys follow PROFILE (iPadOS default 1 / 2).

Rest, soft, and hard wizard

Analog modules only (FSR / HALL / LOAD). Method 3 mechanical clicks do not need analog CAL.

  1. Rest the stick, then TARE.
  2. Hold the student’s soft press, start CAL SOFT, then stop.
  3. Hold the student’s hard press, start CAL HARD, then stop.
