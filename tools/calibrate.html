Stick-Switch calibrator

USB serial at 115200 baud. Open this page in Chrome or Edge (GitHub Pages is HTTPS, which Web Serial requires). Safari and Firefox cannot use Web Serial.

Plug the board in over USB (full kit: slide the power switch OFF while programming; USB-bank kit has no slide). Then connect here. Wired-only kits have no ESP32 — they do not use this calibrator. Calibration auto-saves to NVS; SAVE is only a confirmation dump. HID keys follow PROFILE (iPadOS default 1 / 2). Set PACK USB when there is no AA pack. The cable tester checks USB data with any browser-visible device; it does not test 3.5 mm PowerLink / TS cords.

Request the USB serial port, then open it at 115200. Disconnect when you unplug the board.

Cable tester

Plug a known-working USB device on the far end of the cable under test, then click a button and pick that device in the browser prompt. A keyboard, mouse, gamepad, ESP32, or USB-UART adapter is enough — Stick-Switch is not required.

This only infers a USB data path (D+/D−). Charge-only cables, broken data wires, and “nothing plugged in” all look the same: no device in the picker. Phones often never appear to Web Serial or WebHID. 3.5 mm TS / PowerLink cords are not USB — check those with a continuity meter (or a future jack loopback), not this tool.

Rest, soft, and hard wizard

Analog modules only (FSR / HALL / LOAD). Method 3 mechanical clicks do not need analog CAL.

  1. Rest the stick, then TARE.
  2. Hold the student’s soft press, start CAL SOFT, then stop.
  3. Hold the student’s hard press, start CAL HARD, then stop.
